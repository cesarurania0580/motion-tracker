## Spectroscopy: final agreed workflow

**Calibrate wavelengths → Adjust sampling line → Explore spectrum.** This replaces
the sampling-first iteration tried earlier today.

1. Enter each known wavelength, then use Locate Reference on image. Until a positive
   value exists, the action is disabled with an explanation. During placement the
   action is highlighted, the cursor is a crosshair, and an instruction over the
   image identifies the reference number and entered wavelength. Numbered cyan/red
   markers match the sidebar; they support dragging in calibration and Reposition.
   Validation explains the next missing or invalid input. Guide alignment is optional.
2. Opening Adjust sampling line creates a centered line only if none exists.
   Existing endpoints, width and channel survive reopening. Drag the line or its
   endpoint handles; width is immediately visible and has a translucent sampling
   band. Draw/Replace/Remove line controls and repeated Next buttons were removed.
3. Explore summarizes the intended axis units and opens the graph when samples
   exist. Analysis has Edit sampling / calibration, Compare elements and Export
   spectrum. Color-channel selection was already present in Analysis and remains
   there; only the duplicate sidebar selector was removed.

Step headers remain visible with one open section. Completion checkmarks, a temporary
three-cycle cyan cue and short next-step text guide progression without automatic
navigation. Reduced motion suppresses the pulse. Pixel-only bypass remains available
without deleting calibration. Step changes cancel unfinished placement; sampling
activation pauses playback/manual tracking and invalidates automatic acquisition.
